# Qveto Platform — API Contract & Developer Interface Guide

**Team:** Team Nexora  
**Specification Owner:** Platform Foundation & Auth (Nishant Maurya / Team Lead)  
**Version:** 1.0.0  
**Base URL:** `http://localhost:4000/api` (Production: `/api`)

---

## 1. Architecture & Security Overview

The Qveto Platform REST API is a multi-tenant backend built with Express, TypeScript, and PostgreSQL (Prisma ORM). All resources belong to an Organization (Tenant), and every request is verified server-side against the authenticated user's organization membership and role.

Client applications must never pass an unverified `orgId` expecting authorization. Tenant scoping is strictly enforced through route parameters and database relationships.

---

## 2. Authentication & Session Management

Authentication uses server-managed sessions stored in the PostgreSQL `sessions` table.

- **Cookie Name:** `sessionId`
- **Cookie Security Attributes:**
  - `HttpOnly`: `true` (Tokens cannot be accessed by client-side JavaScript or XSS attacks)
  - `SameSite`: `Lax` (Protects against CSRF attacks across origins)
  - `Secure`: `true` in production (`https://`), `false` in local development (`http://`)
  - `Path`: `/`
  - `Max-Age`: 7 days (`604,800,000` ms)
- **Bearer Token Fallback:** For mobile or programmatic API consumers, the API also accepts:
  ```http
  Authorization: Bearer <sessionId>
  ```
- **Session Cleanup:** Expired sessions are automatically rejected with `401 UNAUTHORIZED` and cleaned up asynchronously.

## 3. Standard Request & Response Contracts

### 3.1 Request Headers
| Header | Description | Required |
|---|---|---|
| `Content-Type` | `application/json` | Required for POST/PUT/PATCH |
| `Cookie` | `sessionId=<id>` | Required for protected endpoints |
| `X-Request-ID` | Unique tracing UUID | Optional (Generated by server if missing) |

### 3.2 Standard Error Response Shape
All errors return consistent, predictable JSON. Stack traces and database internals are never leaked to clients.

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid request data",
    "details": [
      {
        "field": "email",
        "message": "Invalid email address"
      }
    ],
    "requestId": "48cc5f5b-3790-43a2-9487-86bd6d2f7818"
  }
}
```

#### Common Error Codes
| HTTP Status | Error Code | Description |
|---|---|---|
| `400` | `BAD_REQUEST` / `VALIDATION_ERROR` | Schema validation error or invalid operation |
| `401` | `UNAUTHORIZED` / `INVALID_CREDENTIALS` | Missing session, expired session, or bad credentials |
| `403` | `FORBIDDEN` | Insufficient role or cross-organization denial |
| `404` | `NOT_FOUND` | Resource does not exist or route unmatched |
| `409` | `CONFLICT` | Unique constraint violation (e.g. duplicate email) |
| `500` | `INTERNAL_ERROR` | Unexpected server failure |

### 3.3 Standard Pagination Shape
```json
{
  "data": [],
  "meta": {
    "total": 100,
    "page": 1,
    "pageSize": 20,
    "totalPages": 5
  }
}
```

## 4. Shared Enums & Constants

All enums are defined in `@qveto/shared` and mirrored in Prisma schema.

### 4.1 Organization Roles (`OrgRole`)
| Role | Description |
|---|---|
| `OWNER` | Full administrative control over organization settings, workspaces, and member roles |
| `MANAGER` | Manages workspaces, teams, projects, and task assignments; cannot mutate org settings |
| `EMPLOYEE` | Standard member; accesses assigned resources, updates tasks, and collaborates |

### 4.2 Task Statuses (`TaskStatus`)
- `TODO`: Work backlog
- `IN_PROGRESS`: Actively being worked on
- `IN_REVIEW`: Awaiting review / PR verification
- `DONE`: Completed

### 4.3 Task Priorities (`TaskPriority`)
- `LOW`: Routine, non-blocking
- `MEDIUM`: Standard sprint priority
- `HIGH`: Urgent blocker or sprint priority
- `URGENT`: Critical path / immediate resolution needed

## 5. Roles & Permissions Matrix

| Action | OWNER | MANAGER | EMPLOYEE | Non-Member |
|---|:---:|:---:|:---:|:---:|
| **View Org Details** | ✅ | ✅ | ✅ | ❌ (403) |
| **Update Org Settings** | ✅ | ❌ (403) | ❌ (403) | ❌ (403) |
| **List Org Members** | ✅ | ✅ | ✅ | ❌ (403) |
| **Add / Invite Member** | ✅ | ❌ (403) | ❌ (403) | ❌ (403) |
| **Change Member Role** | ✅ | ❌ (403) | ❌ (403) | ❌ (403) |
| **Remove Member** | ✅ | ❌ (403) | ❌ (403) | ❌ (403) |
| **Cross-Tenant Access** | ❌ (403) | ❌ (403) | ❌ (403) | ❌ (403) |

> **Safeguard Note:** The sole `OWNER` of an organization cannot be demoted or removed. Another owner must be designated first.

## 6. Endpoints Reference

### 6.1 System Health
#### `GET /api/health`
Returns health status, uptime, and server timestamp.
- **Auth:** None
- **Response (200 OK):**
  ```json
  {
    "status": "ok",
    "timestamp": "2026-10-15T04:28:13.000Z",
    "uptime": 124.5,
    "environment": "development"
  }
  ```

---

### 6.2 Authentication

#### `POST /api/auth/register`
Creates a new user account, creates an active session, and sets an `HttpOnly` cookie.
- **Auth:** None
- **Body:**
  ```json
  {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "password": "Password123!"
  }
  ```
- **Response (201 Created):**
  ```json
  {
    "user": {
      "id": "usr_cuid...",
      "email": "jane@example.com",
      "name": "Jane Doe",
      "avatarUrl": null,
      "createdAt": "2026-10-15T04:28:13.000Z"
    }
  }
  ```

#### `POST /api/auth/login`
Validates credentials, creates a new session, and sets an `HttpOnly` cookie.
- **Auth:** None
- **Body:**
  ```json
  {
    "email": "jane@example.com",
    "password": "Password123!"
  }
  ```
- **Response (200 OK):**
  ```json
  {
    "user": {
      "id": "usr_cuid...",
      "email": "jane@example.com",
      "name": "Jane Doe",
      "avatarUrl": null,
      "createdAt": "2026-10-15T04:28:13.000Z"
    }
  }
  ```

#### `POST /api/auth/logout`
Destroys session in database and clears the `sessionId` cookie.
- **Auth:** None (or Session Cookie)
- **Response (200 OK):**
  ```json
  {
    "success": true,
    "message": "Logged out successfully"
  }
  ```

#### `GET /api/auth/me`
Returns currently authenticated user profile.
- **Auth:** Required (`sessionId` cookie or Bearer header)
- **Response (200 OK):**
  ```json
  {
    "user": {
      "id": "usr_cuid...",
      "email": "jane@example.com",
      "name": "Jane Doe",
      "avatarUrl": null,
      "createdAt": "2026-10-15T04:28:13.000Z"
    }
  }
  ```

### 6.3 Organizations (Multi-Tenancy)

#### `POST /api/organizations`
Creates a new organization. The creator is automatically assigned the `OWNER` role. A default workspace ("General") is generated.
- **Auth:** Required
- **Body:**
  ```json
  {
    "name": "Acme Innovations",
    "description": "Enterprise workspace"
  }
  ```
- **Response (201 Created):**
  ```json
  {
    "organization": {
      "id": "org_cuid...",
      "name": "Acme Innovations",
      "slug": "acme-innovations",
      "description": "Enterprise workspace",
      "role": "OWNER",
      "createdAt": "2026-10-15T04:28:13.000Z",
      "updatedAt": "2026-10-15T04:28:13.000Z"
    }
  }
  ```

#### `GET /api/organizations`
Lists all organizations the authenticated user belongs to.
- **Auth:** Required
- **Response (200 OK):**
  ```json
  {
    "organizations": [
      {
        "id": "org_cuid...",
        "name": "Nexora Corp",
        "slug": "nexora-corp",
        "description": "Primary Project Management SaaS Tenant",
        "role": "OWNER",
        "memberCount": 3,
        "createdAt": "2026-10-15T04:28:13.000Z",
        "updatedAt": "2026-10-15T04:28:13.000Z"
      }
    ]
  }
  ```

#### `GET /api/organizations/:id`
Retrieves details for a specific organization. Denies access if the user is not a member.
- **Auth:** Required (`requireOrgMember`)
- **Response (200 OK):**
  ```json
  {
    "organization": {
      "id": "org_cuid...",
      "name": "Nexora Corp",
      "slug": "nexora-corp",
      "description": "Primary Project Management SaaS Tenant",
      "role": "OWNER",
      "memberCount": 3,
      "workspaces": [
        {
          "id": "ws_cuid...",
          "name": "Engineering",
          "description": "Core software engineering and infrastructure",
          "orgId": "org_cuid..."
        }
      ]
    }
  }
  ```

#### `PATCH /api/organizations/:id`
Updates organization name or description. Restricted to `OWNER`.
- **Auth:** Required (`requireOrgRole(['OWNER'])`)
- **Body:**
  ```json
  {
    "name": "Nexora Global Corp"
  }
  ```
- **Response (200 OK):**
  ```json
  {
    "organization": {
      "id": "org_cuid...",
      "name": "Nexora Global Corp",
      "slug": "nexora-corp"
    }
  }
  ```

#### `GET /api/organizations/:id/members`
Lists all members in the organization.
- **Auth:** Required (`requireOrgMember`)
- **Response (200 OK):**
  ```json
  {
    "members": [
      {
        "id": "mem_cuid...",
        "userId": "usr_cuid...",
        "orgId": "org_cuid...",
        "role": "OWNER",
        "joinedAt": "2026-10-15T04:28:13.000Z",
        "user": {
          "id": "usr_cuid...",
          "name": "Nishant Maurya",
          "email": "owner@nexora.com",
          "avatarUrl": null,
          "createdAt": "2026-10-15T04:28:13.000Z"
        }
      }
    ]
  }
  ```

#### `POST /api/organizations/:id/members`
Adds a registered user to the organization by email. Restricted to `OWNER`.
- **Auth:** Required (`requireOrgRole(['OWNER'])`)
- **Body:**
  ```json
  {
    "email": "engineer@nexora.com",
    "role": "EMPLOYEE"
  }
  ```
- **Response (201 Created):**
  ```json
  {
    "member": {
      "id": "mem_cuid...",
      "userId": "usr_cuid...",
      "orgId": "org_cuid...",
      "role": "EMPLOYEE",
      "joinedAt": "2026-10-15T04:28:13.000Z",
      "user": {
        "id": "usr_cuid...",
        "name": "Engineer Name",
        "email": "engineer@nexora.com"
      }
    }
  }
  ```

#### `PATCH /api/organizations/:id/members/:userId`
Updates a member's role (`OWNER`, `MANAGER`, `EMPLOYEE`). Restricted to `OWNER`.
- **Auth:** Required (`requireOrgRole(['OWNER'])`)
- **Body:**
  ```json
  {
    "role": "MANAGER"
  }
  ```
- **Response (200 OK):**
  ```json
  {
    "member": {
      "id": "mem_cuid...",
      "userId": "usr_cuid...",
      "role": "MANAGER"
    }
  }
  ```

#### `DELETE /api/organizations/:id/members/:userId`
Removes a member from the organization. Restricted to `OWNER`.
- **Auth:** Required (`requireOrgRole(['OWNER'])`)
- **Response (200 OK):**
  ```json
  {
    "success": true,
    "message": "Member removed successfully"
  }
  ```
